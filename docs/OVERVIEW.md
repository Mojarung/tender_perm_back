# Калькулятор НМЦК — Обзор решения

## Что делает система

Помогает заказчикам госзакупок рассчитать **Начальную Максимальную Цену Контракта** (НМЦК) по методу сопоставимых рыночных цен.

Вместо того чтобы вручную искать аналоги и считать формулы, система:
1. Принимает название товара
2. Автоматически находит похожие товары в каталоге из 244 000 позиций
3. Собирает реальные цены из 450 000 контрактов
4. Отсекает выбросы
5. Считает НМЦК по формулам из Приказа №567
6. Генерирует документ-обоснование

При этом человек контролирует каждый шаг: может убрать неподходящие аналоги, добавить свои цены, вернуться назад и пересчитать.

## Ключевые решения

### Почему Polars, а не Pandas
450 000 контрактов. Polars обрабатывает их в 5-10 раз быстрее за счёт многопоточности и zero-copy. Фильтрация по CTE ID + регион + единица занимает миллисекунды.

### Почему характеристики сравниваются с весами
"Мусорные пакеты 35л" и "Мусорные пакеты 240л" — названия похожи на 95%, но цена отличается в 4 раза. Поэтому при сравнении объём весит x3, материал x2.5, цвет x1. Это позволяет находить реально похожие товары.

### Почему каскад регионов
89% данных — Москва. Если пользователь из Перми, у него может быть 0 "своих" цен. Каскад: сначала свой регион → если мало, все регионы. Цены из других регионов помечаются, чтобы пользователь видел разницу.

### Почему эмбеддинги опциональны
Индексация 244K товаров на CPU — несколько часов. Для демо хватает поиска по категории + характеристикам (покрывает 97.5% случаев). Эмбеддинги добавляют "понимание смысла" (находят "Мешки для мусора" когда ищут "Мусорные пакеты"), но не обязательны.

### Почему IQR для выбросов
Прозрачная формула, которую можно записать в документ обоснования. Стабильна при малых выборках (от 4 значений). Если после фильтрации осталось < 3 цен, IQR смягчается (коэффициент 2.5 вместо 1.5).

## Преимущества решения

### 1. Полностью оффлайн
Никаких внешних API. Данные, модели, БД — всё локально. Можно развернуть на закрытом сервере без интернета.

### 2. Скорость
- Старт сервера: ~30 секунд (без эмбеддингов)
- Поиск аналогов: < 1 секунды
- Сбор и фильтрация цен: < 100мс
- Расчёт НМЦК: мгновенно

### 3. Прозрачность
Каждый шаг объясняется: почему найден этот аналог (score, совпадение характеристик), почему отсечена эта цена (IQR-диапазон), откуда коэффициент kd. Всё это попадает в документ обоснования.

### 4. Human-in-the-Loop
Система предлагает, человек решает. На каждом шаге можно: убрать/добавить аналоги, убрать/добавить цены, вернуться назад. Ничего не применяется автоматически без подтверждения.

### 5. Соответствие законодательству
Расчёт по формулам Приказа Минэкономразвития №567: среднее арифметическое (не медиана), коэффициент вариации, проверка однородности. Коэффициент пересчёта kd для цен старше 6 месяцев.

### 6. Масштаб данных
244 492 товара, 450 915 контрактов, 5 311 категорий, 95 027 уникальных характеристик. Не демо-заглушка, а реальный объём.

### 7. Умный поиск аналогов
4-этапный каскад: точное совпадение → категория + характеристики → семантический поиск → расширенный поиск. Каждый этап компенсирует слабости предыдущего.

### 8. Готовность к продакшену
Docker Compose, Pydantic валидация, каскадная обработка ошибок (нет цен в регионе → все регионы, нет с нужной единицей → любая единица). Не падает на невалидных данных.
