# API Документация — Калькулятор НМЦК

## Что это

Бэкенд-сервис для расчёта Начальной Максимальной Цены Контракта (НМЦК) методом сопоставимых рыночных цен по Приказу Минэкономразвития №567.

Система работает полностью оффлайн: анализирует каталог из 244 492 товаров (СТЕ) и 450 915 контрактов, находит аналоги, собирает цены, фильтрует выбросы и считает НМЦК.

---

## Как работает пайплайн

Весь процесс расчёта — это пошаговый пайплайн с возможностью вернуться на любой шаг:

```
Пользователь вводит товар
        │
        ▼
┌───────────────────┐
│ 1. Поиск аналогов │  POST /api/sessions
│    (автоматически)│  → 20 похожих товаров
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│ 2. Подтверждение  │  POST /api/sessions/{id}/approve-analogs
│    аналогов       │  → цены из контрактов
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│ 3. Подтверждение  │  POST /api/sessions/{id}/approve-prices
│    цен            │  → расчёт НМЦК
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│ 4. Результат НМЦК │  POST /api/sessions/{id}/approve-calculation
│    + документ     │  → .docx обоснование
└───────────────────┘

На каждом шаге можно вернуться назад:
  POST /api/sessions/{id}/go-back
```

## Эндпоинты

### Вспомогательные

#### `GET /api/cte/search?q={запрос}&limit={число}`

Поиск товаров в каталоге СТЕ по названию (автокомплит для UI).

```json
// GET /api/cte/search?q=Ручка шариковая&limit=3
[
  {
    "cte_id": 37089023,
    "name": "Ручка шариковая Berlingo \"Tribase grip orange\" черная 0,5 мм",
    "category": "Ручки канцелярские",
    "manufacturer": "ООО \"ХАТБЕР-М\""
  }
]
```

#### `GET /api/regions`

Список всех регионов из данных.

```json
["Алтайский край", "Москва", "Пермский край", ...]
```

### Основной пайплайн

#### Шаг 1. `POST /api/sessions` — Создание сессии

Создаёт сессию расчёта и автоматически ищет аналоги.

**Запрос:**
```json
{
  "target_cte_name": "Ручка шариковая",
  "target_cte_id": 37089023,
  "target_quantity": 100,
  "target_unit": "шт",
  "target_region": "Москва"
}
```

- `target_cte_id` — необязательный, если известен конкретный товар из каталога
- `target_region` — необязательный, если не указан — ищем по всем регионам

**Ответ:**
```json
{
  "session_id": "c982405b-...",
  "current_step": "wait_analog_approval",
  "found_analogs": [
    {
      "cte_id": 37089023,
      "name": "Ручка шариковая Berlingo ...",
      "category": "Ручки канцелярские",
      "cosine_score": 1.0,
      "char_match_score": 1.0,
      "combined_score": 1.0,
      "source": "exact",
      "match_details": {}
    },
    {
      "cte_id": 37177004,
      "name": "Ручка шариковая Berlingo ... синяя",
      "source": "category",
      "combined_score": 0.63,
      "match_details": {"Цвет": {"status": "string", "score": 0.0}, ...}
    }
  ]
}
```

**Как ищутся аналоги:**
1. **Exact match** — если указан `cte_id`, проверяем есть ли по нему контракты
2. **По категории** — берём все товары из той же категории и сравниваем характеристики (объём, материал, тип и т.д.) с весами
3. **Семантический поиск** — (требует включения эмбеддингов) находит похожие по смыслу товары через Qdrant

---

#### Шаг 2. `POST /api/sessions/{id}/approve-analogs` — Подтверждение аналогов

Пользователь выбирает подходящие аналоги, система собирает цены.

**Запрос:**
```json
{
  "approved_cte_ids": [37089023, 37177004, 37757848]
}
```

**Ответ:**
```json
{
  "current_step": "wait_price_approval",
  "all_prices": [...],
  "valid_prices": [
    {
      "cte_id": 37089023,
      "cte_name": "Ручка шариковая Berlingo ...",
      "price_original": 10.14,
      "price_adjusted": 10.14,
      "kd": 1.0,
      "date": "2025-06-04",
      "region": "Москва",
      "contract_id": 204746787,
      "vat_rate": "20%",
      "unit": "шт",
      "is_outlier": false,
      "is_regional": true
    }
  ],
  "outlier_prices": [],
  "outlier_justification": "Q1=12.33, Q3=24.87, IQR=12.54. Отсечено 0 из 13.",
  "region_fallback_used": false
}
```

**Что происходит внутри:**
1. Сбор цен из контрактов по одобренным CTE ID
2. Каскад по регионам: сначала свой регион → если мало цен, все регионы
3. Каскад по единицам: если нет цен с нужной единицей — ищем с любой
4. Пересчёт давности (kd): цены старше 6 месяцев умножаются на 1.05
5. Фильтрация выбросов методом IQR (межквартильный размах)

---

#### Шаг 3. `POST /api/sessions/{id}/approve-prices` — Подтверждение цен

Пользователь подтверждает цены и может добавить свои.

**Запрос:**
```json
{
  "approved_price_indices": [0, 1, 2, 3],
  "manual_prices": [
    {"price": 25.0, "source_description": "Коммерческое предложение ООО Рога"}
  ]
}
```

**Ответ:**
```json
{
  "current_step": "wait_calc_approval",
  "nmcc_result": {
    "mean_price": 19.07,
    "sigma": 8.74,
    "cv_percent": 45.83,
    "is_homogeneous": false,
    "nmcc": 1906.77,
    "prices_used": 13,
    "quantity": 100,
    "interpretation": "НЕОДНОРОДНАЯ ВЫБОРКА — требуется пересмотр"
  }
}
```

**Формулы (Приказ 567):**
- Средняя цена: `⟨Ц⟩ = Σ Цᵢ / n`
- СКО: `σ = √(Σ(Цᵢ - ⟨Ц⟩)² / n)`
- Коэффициент вариации: `V = σ / ⟨Ц⟩ × 100%`
- НМЦК: `НМЦК = ⟨Ц⟩ × количество`
- Если V > 33% — выборка неоднородна, рекомендуется пересмотр

---

#### Шаг 4. `POST /api/sessions/{id}/approve-calculation` — Подтверждение расчёта

**Запрос:**
```json
{"approved": true}
```

Если `approved: false` — возвращает на шаг подтверждения цен.

---

#### `POST /api/sessions/{id}/go-back` — Возврат на шаг

```json
{"target_step": "analogs"}   // вернуться к выбору аналогов
{"target_step": "prices"}    // вернуться к выбору цен
```

---

#### `GET /api/sessions/{id}` — Получить состояние сессии

Возвращает полное состояние: все аналоги, цены, результат НМЦК.

---

#### `GET /api/sessions/{id}/document` — Скачать документ обоснования

Возвращает .docx файл (после подтверждения расчёта).

## Настройки

Через переменные окружения или `.env` файл:

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `CTE_JSON_PATH` | `data/cte.json` | Путь к каталогу СТЕ |
| `CONTRACTS_JSON_PATH` | `data/contracts.json` | Путь к контрактам |
| `ENABLE_EMBEDDINGS` | `false` | Включить семантический поиск |
| `QDRANT_HOST` | `localhost` | Хост Qdrant |
| `QDRANT_PORT` | `6333` | Порт Qdrant |
| `EMBEDDING_MODEL` | `perplexity-ai/pplx-embed-v1-0.6b` | Модель эмбеддингов |

---

## Коды ответов

| Код | Когда |
|-----|-------|
| 200 | Успешный запрос |
| 404 | Сессия не найдена / документ не сгенерирован |
| 422 | Невалидные данные (неправильный JSON, отрицательная цена) |
